# Красивый просмотр Markdown в терминале

> Как читать `.md` файлы прямо в консоли — с заголовками, таблицами и подсветкой, без открытия редактора

---

## Короткий ответ

| Инструмент | Что делает | Когда брать |
|---|---|---|
| **`glow`** | **рендерит** Markdown как готовый документ | читать заметку «как статью» |
| **`bat`** | **подсвечивает** исходный текст (не рендерит) | смотреть код, `.c`/`.py`/Makefile, или Markdown «как есть» |

Для чтения документации → **`glow`**. Для просмотра кода с подсветкой → **`bat`**.

Проверить, что установлено:
```bash
command -v glow bat less
```

---

## 🥇 glow — рендер Markdown

`glow` превращает `.md` в оформленную страницу: крупные заголовки, таблицы в рамках,
подсветка `кода`, буллеты у списков. Не просто текст — готовый документ.

### Базовое использование
```bash
glow knowledge/cpu_architectures_and_compatibility.md
```
Откроется в пейджере (как `less`). Листать: стрелки / `PageUp` / `PageDown`. Выход: `q`.

### Полезные варианты
```bash
# вывести в поток без пейджера (удобно для | grep, копирования)
glow file.md | less -R

# задать ширину под свой терминал
glow -w 100 file.md

# ⭐ режим-каталог: меню из всех .md в папке, выбираешь стрелками
glow knowledge/

# выбрать тему оформления
glow -s dark file.md      # тёмная
glow -s light file.md     # светлая

# glow умеет читать и по сети — Markdown с URL или из GitHub-репо
glow https://raw.githubusercontent.com/user/repo/main/README.md
```

### Фишка: `glow <папка>`
`glow knowledge/` открывает **меню** из всех заметок в папке — листаешь стрелками,
жмёшь Enter, читаешь. По сути — читалка всей базы знаний одной командой.

## 🥈 bat — «улучшенный cat»

`bat` = `cat` со стероидами: **подсветка синтаксиса**, номера строк, интеграция с git.
Markdown он **не рендерит** (заголовки останутся с `#`), но красиво подсвечивает как исходник.
Отлично для кода: `.c`, `.py`, `Makefile`, конфиги.

### Базовое использование
```bash
bat knowledge/cpu_architectures_and_compatibility.md
bat lowlevel/01_c_foundations/memory_02.c        # код с подсветкой + номера строк
```

### Полезные варианты
```bash
bat -n file.c            # только номера строк, без прочего оформления
bat -A file.txt          # показать невидимые символы (пробелы, табы, \n) — полезно для отладки
bat -l c script          # подсветить как C, даже если у файла нет расширения .c
bat file1 file2 file3    # несколько файлов подряд, каждый с шапкой-именем

# заменить обычный cat в системе (по желанию, алиасом — см. ниже)
```

> ⚠️ На некоторых дистрибутивах бинарь называется `batcat` (Debian/Ubuntu), а не `bat`.
> Проверить: `command -v bat batcat`. На Arch — обычно `bat`.

## 💡 Лайфхаки: алиасы в ~/.zshrc

Разработчики вешают алиасы на всё, что делают часто. Добавь в `~/.zshrc`:

```bash
# kn = knowledge: открыть меню всех заметок
alias kn='glow ~/learn/knowledge/'

# читать любой .md красиво
alias md='glow'

# заменить cat на bat (подсветка везде)
alias cat='bat'
```

Применить изменения без перезапуска терминала:
```bash
source ~/.zshrc
```

Теперь из любой папки: `kn` — база знаний, `md file.md` — красивая заметка,
`cat file.c` — код с подсветкой.

## Offline-first: где искать больше

```bash
glow --help          # быстрый список опций
man glow             # полная документация (если установлена)
bat --help
man bat
```

Смысл всего этого — читать заметки и код **прямо в терминале**, за секунду,
не открывая тяжёлый редактор. Это часть навыка «жить в консоли».

---

## Шпаргалка

- `glow file.md` — прочитать заметку как документ (выход `q`).
- `glow knowledge/` — меню всех заметок, выбор стрелками.
- `glow -s dark file.md` — сменить тему.
- `bat file.c` — код с подсветкой и номерами строк.
- `bat -A file` — показать невидимые символы (пробелы/табы).
- Алиас `kn='glow ~/learn/knowledge/'` — база знаний одной командой.
- `--help` / `man` — offline-справка по каждому инструменту.
